The notebook pulls a company's latest annual report straight from the SEC (10-K for US companies, 20-F for foreign ones), rebuilds the three financial statements, works out what kind of company it is, and then values it with the right model: a growth-stage DCF for AI and high-growth tech, and a standard DCF for everything else. Both are run side by side, with a reverse DCF showing what the market is pricing in.

No paid data, no API keys. Runs in Google Colab in one click.
